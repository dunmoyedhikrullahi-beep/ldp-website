# Lekan Dunmoye & Partners — Nigerian Surveying & Real Estate Agency

LDP is presented as a Nigerian surveying and real estate agency specializing in houses and land.

## Before publishing
- Replace demonstration listings with verified Nigerian properties.
- Add real locations, prices, photos and availability.
- Replace `Lekandunmoye@gmail.com` in `app.js` with LDP’s official email.
- Verify all company contact details.

## GitHub Pages
Upload `index.html`, `style.css`, and `app.js` to a GitHub repository root. Then use Settings → Pages → Deploy from a branch → main → /(root) → Save.
